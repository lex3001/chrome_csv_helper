# Chrome Web Store Listing

## Name
Clipboard Transformer

## Short Description (132 characters max)
Transform clipboard data between CSV, TSV, JSON, and JOOQ formats instantly. Auto-detects format and converts with one click.

## Detailed Description

Transform your clipboard data between multiple formats instantly with Clipboard Transformer! Whether you're copying data from Google Sheets, working with CSV files, or converting JSON to tables, this lightweight extension makes format conversion effortless.

**KEY FEATURES:**

🔍 **Smart Auto-Detection**
Automatically identifies your clipboard format:
• CSV (comma-separated)
• CSV (pipe-separated) 
• TSV (tab-separated - Google Sheets format)
• JSON (objects or arrays)
• JOOQ-style value lists

🔄 **One-Click Conversions**
Convert between any supported formats with a single button click. No typing, no manual formatting—just click and paste.

⚡ **Lightning Fast**
Runs entirely in your browser with no external dependencies. Your data never leaves your computer.

📋 **Seamless Clipboard Integration**
Reads from and writes to your clipboard automatically. Copy, click, and paste—it's that simple.

🎨 **Clean, Minimal Interface**
No clutter, no complexity. Just the tools you need to get your work done.

**PERFECT FOR:**

• Data analysts working between spreadsheets and databases
• Developers converting API responses to test data
• Anyone who copies and pastes tabular data regularly
• Teams working with different data formats
• Creating SQL INSERT statements from spreadsheet data

**HOW IT WORKS:**

1. Copy any tabular data to your clipboard (from Google Sheets, CSV files, JSON APIs, etc.)
2. Click the Clipboard Transformer icon in your Chrome toolbar
3. See your format automatically detected
4. Click the target format button (CSV, TSV, JSON, or JOOQ)
5. Your converted data is instantly copied to clipboard—ready to paste!

**SUPPORTED CONVERSIONS:**

✓ Google Sheets ↔ CSV (comma)
✓ Google Sheets ↔ CSV (pipe)  
✓ Google Sheets ↔ JSON
✓ CSV ↔ JSON
✓ CSV ↔ JOOQ value lists
✓ JSON ↔ TSV (Google Sheets)
✓ And many more combinations!

**TECHNICAL HIGHLIGHTS:**

• Handles quoted fields, commas in values, and escaped quotes correctly
• Preserves data integrity during conversion
• Supports JSON objects and arrays
• Converts JSON objects to tables with automatic header detection
• Generates JOOQ-style value lists for SQL INSERT statements
• Works completely offline—no internet required

**PRIVACY & SECURITY:**

🔒 Your privacy is paramount:
• NO data transmission - everything processes locally in your browser
• NO tracking or analytics
• NO external API calls
• NO third-party libraries
• Your data never leaves your computer

**EASY FALLBACK OPTIONS:**

If automatic clipboard detection doesn't work due to browser permissions:
• Manual "Detect clipboard" button available
• Or paste your data directly into the text area

**USE CASES:**

📈 **Reporting**: Transform JSON data to tables for Google Sheets

Unlike other conversion tools that require:

Clipboard Transformer works directly in Chrome, processes everything locally, and is completely free to use forever.

**PERMISSIONS EXPLAINED:**

• **Storage**: Saves your preference for automatic clipboard detection
• **Clipboard Read/Write**: Reads data from and writes converted data to your clipboard

We only request the minimum permissions needed. Your data stays private and secure.

## Privacy Policy (Required)
**Clipboard Transformer Privacy Policy**

Last updated: November 23, 2025

Clipboard Transformer ("the Extension") is committed to protecting your privacy. This policy explains our data practices.

**Data Collection:**
We do NOT collect, store, transmit, or share any personal data or clipboard contents. All data processing happens locally in your browser.

**Permissions:**
• Storage: Used only to store your preference for automatic clipboard detection
• Clipboard Read/Write: Used to read from and write to your clipboard for format conversion
